NEStroid REIMAGINED
---
Relive the 80s classic with modern features, user generated content, and endless planets to explore!

An engine built from the ground up to evoke the feel and style of NEStroid, while adding improvements to the graphics, sound, and mechanics. The engine supports multiple "planets", which are essentially their own games.

There are a few built-in planets, one of which is the original NEStroid world. However, the main focus is on randomly generated worlds using player designed rooms. Use the in-game editor to create rooms for the generator to use, and share them with the community!

The engine also features online multiplayer!

Modern Features
---
 + Gameplay
   + Sharper Movement/Combat
   + Map System
   + Equipment Menu, turn items on/off
   + Customizable Controls
   + Saves instead of Passcodes
   + Multiple difficulties (Easy/Normal/Hard)
 + Audio/Visual
   + Improved Animations
   + Remixed 8-bit Audio using the VRC6 sound chip
   + Optional HUD content (Item Percentage / Timer / Mini-map)
   + Optional Particle Effects
 + New ways to play the 80s Classic
   + Earn points by beating the game to unlock extra modes below (or connect with a friend so they can give you points!)
   + Randomized Mode - Item locations will be swapped randomly
   + Randomized+ Mode - Features additional items not found in the original game
   + Strike Mode - Start with all upgrades, but manage a finite amount of Energy and Ammo in the world
 + Multiplayer
   + Host a server for up to 10 people (port-forwarding is required)
   + Customizable Co-op (choose if you share Health, Map, Items, etc)
   + Party style Versus (collect buffs, send debuffs, and race to the finish)


Planet NOVUS - Only on v1.27g
---
Packaged with the first release of the engine, this handcrafted world features an original map and some new content. Due to engine changes this world is not available on current releases, but is planned to be reimplemented in the future.
